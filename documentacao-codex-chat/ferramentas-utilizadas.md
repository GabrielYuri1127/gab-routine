# Ferramentas Utilizadas No Apoio ChatGPT/Codex

## Ambiente

- ChatGPT em modo Codex no desktop.
- Workspace local no Windows.
- PowerShell para comandos locais.
- Navegador integrado para acompanhar telas locais, GitHub, Vercel e Google Cloud quando necessario.

## Ferramentas De Edicao E Inspecao

- `apply_patch` para criar e editar arquivos do projeto.
- `rg` para localizar arquivos e textos rapidamente.
- `Get-Content` para ler arquivos no PowerShell.
- `git status`, `git diff`, `git log`, `git add`, `git commit` e `git push`.

## Ferramentas De Validacao

- `npm run typecheck` para validar TypeScript.
- `npm run lint` para validar regras locais do projeto.
- `npm test` para executar a suite automatizada.
- `npm run build` para validar build de producao.

## Recursos Consultados

- Documentacao publica da OpenAI sobre Codex e ChatGPT.
- Documentacao oficial do Google OAuth e Google Classroom.
- Documentacao oficial da Vercel para variaveis de ambiente e deploy.
- Documentacao oficial da OpenAI para respostas estruturadas da API.

## O Que Nao Foi Guardado

- Chaves de API.
- Tokens OAuth.
- Senhas.
- Cookies.
- Dados privados de contas institucionais.
- Conversa completa com mensagens sensiveis.
