# Registro De Uso Do ChatGPT/Codex

## Objetivo Do Apoio

O apoio de ChatGPT/Codex foi usado para transformar a ideia do GAB ROUTINE em um aplicativo funcional, organizar tarefas de desenvolvimento, editar arquivos do projeto, rodar validacoes e preparar commits para o GitHub.

## Como Foi Usado

1. O usuario descreveu a ideia do aplicativo pessoal e academico.
2. O apoio assistido ajudou a organizar o escopo em fases praticas.
3. O codigo foi criado e ajustado dentro do repositorio local.
4. Foram feitas validacoes com TypeScript, lint, testes e build de producao.
5. As alteracoes foram commitadas e enviadas para o GitHub.
6. O projeto ficou preparado para deploy na Vercel e instalacao como PWA no Android.

## Partes Do Projeto Que Receberam Apoio

- Estrutura Next.js com App Router.
- Interface mobile-first.
- Tela Hoje.
- Area Faculdade.
- Controle de faltas, incluindo registros antigos.
- Controle de notas e simulador.
- Atividades academicas por prazo.
- Tarefas, lembretes e calendario.
- Persistencia local com `localStorage`.
- PWA com manifest, service worker e shortcuts.
- Preparacao de Supabase.
- Integracao Google Classroom por OAuth.
- Suporte a mais de uma conta institucional do Classroom.
- Assistente de IA local por regras.
- Preparacao de IA por API no servidor.
- Tela de tutorial dentro do app.
- Painel de personalizacao do app.
- Documentacao tecnica e material de portfolio.

## Decisoes Importantes Tomadas No Processo

- Manter o app funcionando mesmo sem conta, banco ou chave de IA.
- Usar dados locais primeiro para reduzir dependencia de servicos pagos.
- Deixar chaves privadas apenas no servidor.
- Tratar Google Classroom como importacao revisavel, nao sincronizacao automatica invisivel.
- Separar dados de contas diferentes do Classroom.
- Mostrar na IA a base da resposta e os dados que ainda faltam.
- Manter a area de comercializacao fora do escopo atual.

## Cuidados

- Nenhuma credencial real deve ser registrada aqui.
- Logs completos de terminal nao precisam ser copiados; basta registrar o que foi feito e validado.
- Prints de contas, paineis, tokens ou telas privadas nao devem entrar no repositorio.
