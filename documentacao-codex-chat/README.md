# Documentacao Codex E Chat

Esta pasta concentra o registro de uso de ChatGPT/Codex no projeto Gavium.

Tudo que explicar apoio de conversa, agente de codigo, prompts, fluxo assistido, ferramentas do Codex ou uso do ChatGPT durante a criacao do projeto deve ficar aqui, e somente aqui.

## Arquivos

- `registro-de-uso.md`: resumo do que foi pedido, como o apoio foi usado e quais partes do projeto receberam esse apoio.
- `ferramentas-utilizadas.md`: ferramentas, comandos e recursos usados durante o desenvolvimento assistido.
- `resumo-para-outro-chat.md`: contexto curto para continuar o projeto em outra conversa.

## Limites

- Esta pasta nao guarda chaves, tokens, senhas, cookies ou credenciais.
- Esta pasta nao substitui a documentacao tecnica do app.
- A pasta `portfolio/` deve contar o projeto como produto e estudo de caso, sem detalhar o uso de ChatGPT/Codex.
